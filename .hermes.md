# nextjs-template

Next.js template with batteries included: Atomic Design, Supabase, i18n, auth, design system.

## Quick Start

```bash
pnpm install
cp .env.example .env.local  # Fill in your Supabase credentials
pnpm dev
```

## What's included

- Next.js 16 App Router with route groups `(public)` / `(admin)`
- Supabase SSR (server, browser, middleware clients)
- Database-driven i18n (content_blocks + translations)
- Auth system (login page, OAuth, middleware)
- Atomic Design components (atoms, molecules, organisms)
- Design system with CSS variables, light/dark themes
- Skeleton loading states
- Framer Motion animations
